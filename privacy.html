Footprints（聖書学習記録）／2026年11月10日

保存場所

記録・写真・設定は、利用者の端末のブラウザ内に保存されます。開発者のサーバーには送られません。

Google連携（任意）

  • 利用者が「Google連携」を選んだときだけ、利用者自身のGoogleドライブにデータを保存・取得します。
  • 使う権限は drive.file のみで、アプリが作ったファイル（「Footprints-Sync」フォルダ）以外にはアクセスしません。
  • 表示のため、Googleアカウントのメールアドレスを取得します。
  • データは利用者のドライブと端末の間でのみやり取りされ、開発者や第三者に送信・共有・販売しません。

Google API から受け取った情報の使用と移転は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

削除

アプリの「Google連携を解除」で連携を止められます。ドライブのデータは「Footprints-Sync」フォルダを削除すると消えます。アクセス権は Googleアカウントの設定 からも取り消せます。
